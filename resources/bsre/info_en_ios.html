BSRE Installation Guide

Complete guide from purchase to activation

1. How to Purchase BSRE

1Start the Bot
Open BSRE Bot
Open the link and tap "start" at the very bottom.
If the link shows as invalid, please install Telegram first.
Need support?
2Open Balance
Tap "Balance" on the left side of the screen.
3Select Amount
Tap "2000⭐️".
4Select Payment Method
Select "Telegram stars".
5Complete Payment
Purchase Telegram stars and complete your payment.
6Display Menu
Send "/start" to the bot in the chat to display the menu.
7Product List
Tap "Product list".
8Confirm & Purchase
Tap "NEXT" twice, confirm that it says "bsre" above the message, and then tap "buy now".
9Confirm Stars Price
Tap "⭐️2000".
10Confirm Purchase
Tap "✅Purchase".

2. How to Install BSRE

1Get the App
Tap the "Get" button in the top right.
2Open Telegram
A prompt saying "Open this page in Telegram?" will appear. Tap "Open".
3Download File
Tap the "↓ (Download)" button on the highlighted file to start downloading.
4Save to Files
Once the download is complete, open the share menu and select "Save to Files".
5Select Library
Select the "Library" tab in Ksign.
Don't have Ksign?
6Tap Add Button
Tap the "+" button in the top right.
7Select Import Method
Select "import from files".
8Recent Items
Select the "Recents" tab in the bottom right.
9Select ipa File
Select the BSRE ipa file to import it.
10Select the App
Tap BSRE from the added list.
11Start Signing
Tap "sign&install", then tap "Start signing" on the next screen. Wait for about 5 minutes.
12Complete
Once completed is displayed on the screen, confirm the installation and you're done.
